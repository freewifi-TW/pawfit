# 多語系（i18n）

目前支援：`zh-TW`（預設）、`en`。設計上新增一種語言只要加語言檔，不用改程式碼。

## 架構

| 層 | 做法 |
|---|---|
| 前端（Nuxt） | `@nuxtjs/i18n`，策略 `no_prefix`（網址不帶語言），語言記在 cookie `pawfit_locale`；語言檔在 `apps/web/i18n/locales/<code>/*.json` |
| 登入者偏好 | `users.locale`（BCP 47）。切換語言時前端 PATCH `/api/me { locale }`；登入後 `plugins/04.locale-sync.ts` 以 user.locale 優先 |
| 後端（Laravel） | `SetLocale` middleware：users.locale → `Accept-Language`（前端 useApi 會帶目前語言）→ 預設。訊息在 `apps/api/lang/<code>/messages.php`，Laravel 內建（驗證等）由 laravel-lang 提供 |
| 語言清單 | 前端 `apps/web/nuxt.config.ts` 的 `SUPPORTED_LOCALES`；後端 `config/pawfit.php` 的 `locales.supported`。兩邊要一致 |

前端用 BCP 47（`zh-TW`），Laravel 的 lang 目錄用底線（`zh_TW`），`SetLocale::toLaravel()` 負責轉換。

## 前端語言檔

一個 namespace 一個檔案，檔案最上層 key 就是 namespace 名稱，key 用 camelCase：

```
i18n/locales/zh-TW/common.json    共用：品牌、導覽、按鈕、通用錯誤、頁尾、錯誤頁、語言切換
i18n/locales/zh-TW/enums.json     列舉值顯示文字：visibility / kind / reason / adminAction / nsfwPref（useLabels）
i18n/locales/zh-TW/home.json      首頁
i18n/locales/zh-TW/auth.json      登入、onboarding
i18n/locales/zh-TW/dashboard.json 我的獸設
i18n/locales/zh-TW/fursona.json   獸設編輯器（基本資料、色票、標籤、隱私與分享）
i18n/locales/zh-TW/media.json     圖庫、上傳、圖片編輯、燈箱、卡片
i18n/locales/zh-TW/share.json     分享頁 /s/:slug
i18n/locales/zh-TW/profile.json   個人主頁 /u/:id
i18n/locales/zh-TW/settings.json  設定
i18n/locales/zh-TW/admin.json     管理後台、檢舉
i18n/locales/zh-TW/legal.json     條款、守則、隱私權（長文，段落用陣列）
```

```json
{
  "fursona": {
    "tabs": { "basic": "基本資料", "gallery": "圖庫 {n}" },
    "save": { "button": "儲存", "saved": "已儲存" }
  }
}
```

namespace 清單在 `nuxt.config.ts` 的 `NAMESPACES`；新增 namespace 要在那裡加，且每種語言都要有同名檔案（沒有就放 `{"<ns>": {}}`）。

## 前端寫法

```vue
<script setup lang="ts">
const { t } = useI18n()
const { kindLabel, formatDate } = useLabels()   // 列舉值文字與日期格式
</script>

<template>
  <h1>{{ t('fursona.title') }}</h1>
  <p>{{ t('fursona.tabs.gallery', { n: media.length }) }}</p>     <!-- 插值 -->
  <p>{{ t('media.count', media.length) }}</p>                      <!-- 複數：JSON 值寫 "沒有圖片 | {n} 張圖片" -->
  <span>{{ kindLabel(m.kind) }}</span>
  <time>{{ formatDate(m.created_at, true) }}</time>
</template>
```

- 頁面標題：`useHead({ title: () => t('...') })`，用函式讓語言切換時跟著變。
- `useSeoMeta` 的 og 文字同樣用函式。
- script 內的通知 / 錯誤文字也走 `t()`；不要在模組頂層（setup 之外）呼叫 `useI18n`。
- 列舉值（可見度、圖片類型、檢舉原因…）一律用 `useLabels()`，不要再寫對照表。
- 日期用 `useLabels().formatDate / formatMonth`（底層是 vue-i18n 的 `d()`，格式在 `i18n/i18n.config.ts`）。
- 語言切換元件 `<LocaleSwitcher />`；程式化切換用 `useLocale().switchLocale(code)`。

## 後端寫法

```php
throw ValidationException::withMessages(['pawfit_id' => __('messages.me.pawfit_id_taken')]);
abort(403, __('messages.fursona.not_owner'));
```

- 業務訊息集中在 `lang/<locale>/messages.php`，鍵名依 controller / service 分群（`me.*`、`fursona.*`、`media.*`、`share.*`、`report.*`、`admin.*`、`auth.*`、`image.*`）。
- 驗證欄位名稱在 `lang/<locale>/validation.php` 的 `attributes`。
- 回應會帶 `Content-Language`。
- 測試：`$this->withHeader('Accept-Language', 'en')` 驗證英文訊息。

## 新增一種語言

1. 前端：`nuxt.config.ts` 的 `SUPPORTED_LOCALES` 加一項；複製 `i18n/locales/en/` 為新語言資料夾並翻譯；`i18n/i18n.config.ts` 補日期格式。
2. 後端：`config/pawfit.php` 的 `locales.supported` 加 code；`php artisan lang:add <code>` 產生 Laravel 內建翻譯；複製 `lang/en/messages.php` 翻譯。
3. 語言切換選單會自動出現新語言。
